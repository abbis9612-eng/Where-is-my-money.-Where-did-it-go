# وين فلوسي؟ — Where is my money?

تطبيق لإدارة مال العائلة العراقية: نعرف وين يروح كل دينار، ونبدي ندّخر من أول راتب.
الفكرة («الرزمة»): الراتب يتقسّم أول الشهر لظروف، والباقي يصير رزمة أسبوعية من السبت للجمعة.

## شنو موجود بالتطبيق

| الشاشة | شنو تسوي |
|---|---|
| الأسبوع | رزمة الأسبوع بأوراق دينار حقيقية، الباقي لليوم، «أكدر أشتري؟»، عدّ الجيب بدل تسجيل كل كاش |
| صرفت | كيباد بلمسة، أو جملة «خبز 2 وبنزين 25»، أو صوت (ضغطة طويلة)، وذكاء اصطناعي احتياطي للجمل الصعبة |
| رسائل الكي كارد | تقرأ رسائل البنك وتحطها بصندوق تأكيد بلمسة وحدة (بإذن المستخدم) |
| الظروف | ظروف شهرية، يوم الراتب، الفواتير الثابتة (المولدة، الإنترنت…) تنزل لحالها |
| وين راحت | تقرير الشهر كمخطط تدفق |
| العائلة | بابا وماما كل واحد بحسابه، حساب الطفل وحصّالته، الجمعية، الديون |
| الجمعة | إغلاق الأسبوع: الفائض يروح للحصّالة أو لهدف بالسحب |
| الإعدادات | وضع ليلي، قفل بالبصمة، سعر الدولار، تذكيرات، مزامنة |

البيانات على الموبايل مشفّرة (SQLCipher)، والتطبيق يشتغل كامل بدون نت.
المزامنة بين موبايلات العائلة اختيارية عبر Supabase، وكل عائلة معزولة عن غيرها بقواعد الصفوف (RLS).

## البنية

```
app/        تطبيق Flutter (أندرويد أولاً)
  lib/core      الفلوس والعملات (أعداد صحيحة، دينار ودولار)
  lib/domain    المنطق الصافي: الميزانية، الأوراق النقدية، قراءة الجمل والرسائل، الجمعية
  lib/data      قاعدة البيانات (Drift + SQLite3MultipleCiphers) والمستودع
  lib/sync      المزامنة وتسجيل الدخول بالإيميل وكود الدعوة
  lib/platform  الصوت، الرسائل، التذكيرات، القفل
  lib/ui        الشاشات والثيم
supabase/   قاعدة البيانات على السيرفر، دالة الذكاء الاصطناعي، واختبار عزل العوائل
design/     النماذج الأولية A إلى E2 (كلها محفوظة)
docs/       البحث وقرارات التصميم
```

## التشغيل والاختبار

```bash
cd app
flutter pub get
flutter analyze
flutter test                      # كل الاختبارات
flutter test --tags golden --update-goldens   # يرسم كل الشاشات بـ test/ui/goldens
supabase/tests/run.sh             # (من جذر المستودع) المايكريشنز وعزل العوائل على Postgres محلي
```

## نسخة الأندرويد (APK)

كل push يشغّل [`.github/workflows/android.yml`](.github/workflows/android.yml):
يفحص الكود، يشغّل الاختبارات، يرسم الشاشات، ويبني `app-release.apk`.
تنزّلونه من تبويب **Actions** ← آخر تشغيل ← **Artifacts** ← `ween-floosi-apk`.

محلياً: `flutter build apk --release` (يحتاج Android SDK).
النسخة الحالية موقّعة بمفتاح التطوير؛ قبل النشر على Google Play لازم مفتاح توقيع خاص.

## ربط المزامنة (اختياري)

1. سوّوا مشروع Supabase، وشغّلوا ملفات `supabase/migrations/` بالترتيب.
2. فعّلوا تسجيل الدخول بالإيميل (OTP) بإعدادات Auth.
3. بأسرار المستودع على GitHub حطّوا `SUPABASE_URL` و `SUPABASE_ANON_KEY` — الـ APK يتبنى مربوط تلقائياً.
4. الذكاء الاصطناعي الاحتياطي:
   ```bash
   supabase functions deploy parse-expense
   supabase secrets set ANTHROPIC_API_KEY=...
   ```
   ما ينبعث إلا نص الجملة، بدون أسماء أو أرصدة.

بدون هالخطوات التطبيق يشتغل على موبايل واحد بشكل كامل.
