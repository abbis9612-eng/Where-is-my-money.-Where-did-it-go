# لمسة بركة، الصدقة والزكاة — المصادر وطريقة التحقق

النصوص بـ `app/lib/domain/barakah.dart`، وأحكام الزكاة بـ `app/lib/domain/zakat.dart`.

## طريقة التحقق
- **القرآن:** نص Tanzil (simple-enhanced) عبر api.alquran.cloud، بالتشكيل كما هو.
- **الحديث:** موسوعة الدرر السنية (dorar.net) مع حكم المحدّث، وsunnah.com للترقيم والدرجة.
- ما نعرض إلا الصحيح والحسن. كل حديث خارج الصحيحين وياه درجته واسم اللي حكم عليه.
- الاختبار `app/test/domain/barakah_test.dart` يمنع حذف المصدر أو الدرجة، ويثبّت التصحيحات تحت.

## أحكام الزكاة المعتمدة بالحساب
- **النصاب:** 85 غم ذهب خالص (عيار 24)، أو 595 غم فضة. والنسبة 2.5% (ربع العُشر). المصادر: islamqa 396499 و370380.
- **عيار الذهب:** يُحسب بالوزن الخالص (الوزن × العيار ÷ 24)، كما بـ islamqa 396499. ودار الإفتاء المصرية تعبّر بـ «85 غم عيار 21»، وهذا اصطلاح مختلف.
- **نصاب الفلوس:** بالفضة عند المجمع الفقهي برابطة العالم الإسلامي وهيئة كبار العلماء، وبالذهب عند دار الإفتاء المصرية. التطبيق يخلّي الاختيار للعائلة.
- **الحول:** سنة هجرية (حوالي 354 يوم). مصدره islamqa 207109.
- **ذهب الزينة:** الحنفية يوجبون بيه الزكاة، والجمهور ما يوجبونها.
- **الديون اللي إلكم:** تُحسب إذا المدين مليء باذل.
- **الديون اللي عليكم:** الحنفية والحنابلة يخصمونها، والشافعية ما يخصمونها، والمالكية يخصمونها من النقد. لهذا الخصم اختياري بالتطبيق.
- **زكاة الفطر:**
  - صاع (حوالي 3 كيلو، ابن باز)، عن الصغير والكبير.
  - وقتها قبل صلاة العيد، ويجوز قبل العيد بيوم أو يومين (البخاري 1503 و1511).
  - القيمة يجيزها الحنفية.
  - **1447 هـ / 2026:** المجمع الفقهي العراقي وديوان الوقف السني أعلنوا 3,000 دينار حدًّا أدنى عن الشخص. المصادر: ina.iq/ar/local/255927-3000.html و mawazin.net (5/3/2026).
  - **يحتاج تحديث كل سنة** (`kFitrIraq1447`).

تحتاج مراجعة شيخ أو طالب علم موثوق للنصوص ولشاشة الزكاة. التطبيق ينقل النصوص ومصادرها، وما يفتي.
