## 2. القواعد العشرة المشتركة بين كل المصادر

1. **ابدأ من عالم الموضوع، مو من فئة المتجر.** التميز يجي من مواد الموضوع ورموزه ولغته (Anthropic).
2. **اكتب «قراءة التصميم» بسطر واحد** واضبط ثلاث أقراص: التنوع (1–10)، الحركة (1–10)، الكثافة (1–10) (Taste).
3. **ولّد 7 مرشحين من ثقافة الجمهور** (أشياء، أماكن، طقوس يعرفها الجمهور عن ظهر قلب)، من 3 «عائلات مواد» على الأقل، واستبعد القراءة الحرفية الأولى وعكسها، لأن هذول هم «الأخدود» اللي كل النماذج توقع بيه (Impeccable).
4. **خطة رموز قبل الكود:** 4–6 ألوان مسمّاة بقيمها، عائلة خط أو اثنين بأدوار واضحة، تخطيط بجملة ورسم ASCII، ومبادئ. بعدين **انقد الخطة**: لو موضوع ثاني يوصلك لنفس النتيجة، هذا افتراضي مو قرار (Anthropic).
5. **تجنب الكتل المعروفة** للتصميم المولّد بالذكاء الاصطناعي:
   - خلفية كريمي مع سيريف ولون طيني.
   - أسود مع لون فسفوري واحد.
   - تخطيط جرائد بخطوط شعرية.
   - طقم بطاقات SaaS المتطابقة.
   - عنوان صغير بأحرف كبيرة فوق كل عنوان.
   - أرقام أقسام 01/02/03.
   - النص المتدرّج.
   - حدود ملونة على جانب البطاقات.
   - توهج بنفسجي.
   - أبيض وبيج وبرونزي للمنتجات الفاخرة (كل المصادر).
6. **عنصر توقيع واحد**، واصرف كل الجرأة بيه. الباقي هادئ ومنضبط. وقبل لا تطلع، شيل إكسسوار واحد (Anthropic).
7. **أرضية الجودة:**
   - تباين 4.5:1.
   - كل الحالات: تحميل، فارغ، خطأ، معطّل.
   - أرقام بعرض ثابت للجداول.
   - تركيز لوحة المفاتيح ظاهر.
   - تقليل الحركة محترم.
   - **لحظة حركة وحدة مدروسة** بدل مؤثرات متناثرة.
   - أيقونات من نظام واحد بنفس السمك (Impeccable، Taste).
8. **الكلام جزء من التصميم:** اكتب بلغة المستخدم. الزر يگول شنو يصير، والخطأ يگول شنو صار وشلون ينحل (Anthropic).
9. **ارسم وافحص بجولات محدودة:** ابنِ كامل، صوّر، صلّح كل شي بدفعة وحدة، تأكد مرة وحدة، ووقف (Impeccable، Uizze).
10. **احفظ القرارات بملف DESIGN.md** حتى ما تنحرف الشاشة الثانية عن الأولى (Google Stitch).

## 3. قالب البرومبت الجاهز (انسخه لأي أداة: Claude، Lovable، v0، Stitch)

> النماذج تفهم الإنكليزي أدق بالتعليمات التقنية، فالقالب بالإنكليزي، والمحتوى والنصوص بالعربي.

```text
ROLE: Design lead at a studio known for giving every client an identity no one else can claim.
The client rejected templated proposals. Take one justified aesthetic risk; keep everything else disciplined.

PRODUCT: "وين فلوسي؟" — household money app for Iraqi families (parents + child), Android first, Arabic RTL.
SURFACE MODE: Operate (a task tool used daily, one-handed, often in a shop or at home in the evening).
DESIGN READ (one line): Reading this as <surface> for <audience>, with a <world> language, leaning toward <system>.
DIALS: VARIANCE <1-10> · MOTION <1-10> · DENSITY <1-10>

GROUNDING: List 7 artifacts/places/rituals Iraqi families know by heart, from ≥3 material families.
Exclude the literal reading ("banknotes/money") and its opposite. Pick one world; name what it donates.

TOKEN PLAN before any code:
- 4–6 named colors with hex, each with ONE semantic job
- 1–2 type families (Arabic-first; body line-height ≥1.7; no letter-spacing on Arabic)
- Layout concept in one sentence + ASCII wireframe per screen
- ONE signature element (the thing users remember); one authored motion moment
Then critique the plan against the brief: if a different subject would yield the same plan, revise and say why.

AVOID (unless the brief asks): cream+serif+terracotta; near-black+single neon; broadsheet hairlines;
identical rounded SaaS cards; eyebrow labels; 01/02/03 numbering; gradient text; colored border-left cards;
purple glow; emoji as icons; hero-metric template (big number + small label + stats + gradient).

QUALITY FLOOR: WCAG AA contrast, 48dp targets, tabular numerals for money, empty/error/loading states,
reduced motion, real Arabic copy in Iraqi dialect from the user's side ("صرفت", "نزل الراتب"), no lorem ipsum,
illustrative numbers labeled as such.

PROCESS: plan → critique → build all screens → render screenshots → fix in one batch → verify once → stop.
Save decisions to DESIGN.md.
```

## 4. شلون طبّقته على «التصميم الثاني»

- **قراءة التصميم:** تطبيق تشغيل يومي لعائلة عراقية، بلغة «دفتر البيت»، يميل لواجهة ورقية مسطرة واضحة.
- **الأقراص:** التنوع 6، الحركة 4، الكثافة 4.
- **المرشحين السبعة:**
  1. دفتر المصروف الورقي (الحل اليدوي اللي التطبيق ينافسه).
  2. دفتر المدرسة «أبو الجدول».
  3. البطاقة التموينية.
  4. شناشيل بغداد.
  5. طقس الچاي والاستكان.
  6. لوحات أسعار السوگ المكتوبة باليد.
  7. ألواح الطين السومرية، وهي أول سجلات حسابات بالتاريخ وكانت بالعراق.
- **المستبعد:** «الورقة النقدية والنقش»، وهو القراءة الحرفية اللي انبنى عليها التصميم الأول.
- **المختار:** دفتر البيت المسطّر مع خط الرقعة. والتبرع من البطاقة التموينية: «الختم» والتقسيم الشهري الصارم.
